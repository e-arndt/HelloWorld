# Overview

As a software engineer, I am working to build a solid and reliable development workflow that includes writing code, testing it, and publishing it through version control. This project represents the first step in validating that my environment is correctly configured and that I can successfully move code from development to a public repository.

This software is a simple command-line program that outputs text to the terminal. When executed, it displays a "Hello World" message along with a short custom message to confirm successful execution.

The purpose of creating this software is to verify that my development tools are properly installed and working together, including my editor, runtime environment, and GitHub integration. It also establishes a baseline process that I will follow for future, more complex projects.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

The software was developed using Visual Studio Code as the primary code editor. Git was used for version control, and GitHub was used to host the public repository.

The programming language used for this project is JavaScript, executed using Node.js in a command-line environment.
